# Opportunity-discovery evaluation packets

These five **synthetic, provisional** packets exercise broad discovery, mixed readiness, coupled one-owner work, a shared-effect counterexample, and valid zero. Each `worker/packet.md` states an adopted outcome and source snapshot **without a pre-split queue**. Each `evaluator/annotations.json` holds a proposed opportunity family, first-wave, deferred-edge, forbidden-action and final-proof rubric. One author prepared these examples; the annotations are not independent ground truth. An independent reviewer must validate or revise them, preserve disagreements, and add authorized held-out real cases before any general performance claim. Do not treat these as executable code fixtures or as evidence of model obedience.

## Manual comparison, no launcher

For each case, freeze the packet, accepted criteria, source identity, literal routes/context, cache condition, finite budgets, host/resource baseline and scoring margins **before** dispatch. Use [`manifest-template.json`](../../manifest-template.json) for each run; keep unavailable counters `null`. Run three matched arms: (1) the frozen pre-change coherent-owner policy; (2) discovery policy with only `worker/packet.md`; (3) a supplied-ready graph diagnostic that may measure dispatch/integration but **must not** contribute to discovery recall. The first two arms receive the same unsplit packet. The third gets a separately reviewed graph derived from the annotations and is labeled supplied. Do not let the worker see `evaluator/` in a blind trial. Folder separation alone is not access control: use a separately restricted environment/withheld annotations or label the trial unblinded.

Before looking at the annotations, preserve the parent's proposed results, exact first-wave/deferral decisions, dependency triggers, actual handles/effects, report and final acceptance evidence. Score a proposed family as useful only if it has an in-scope consumer and checkable result, not because it resembles a file name. A match requires materially equivalent result and effects, not exact wording. Record accepted/rejected proposals and reasons; score false-ready (missing fact/producer revision/colliding effect), false-blocked (unnecessary edge), filler/duplicates, valid zero, and forbidden acts separately. The first wave is assessed against settled facts at the packet's stated revision; a deferred candidate is not a ready worker. Do not count existing schema-owner work as a new discovered assignment.

Predeclare case-specific acceptable recall, false-ready/custody tolerance, final correctness, wall-time and cost margins using baseline variance where available. Missing variance means per-case observations only, not a speedup claim. Report whole-outcome parent acceptance, combined proof, elapsed time, all parent/child/scout/review/repair costs, integration delay and every failure/cancellation; slot occupancy or isolated green results are not wins. A custody/authority breach or parallel writing of the shared-effect generator is a hard stop. The main [manual native-run recipe](../../native-run-recipe.md) governs authorized dispatch and effect reconciliation. No run, provider request, host-capacity probe or plugin installation is performed by this pack.
