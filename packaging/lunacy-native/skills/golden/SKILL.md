# Lunacy Golden

Treat invocation of `$lunacy-native:golden` with an outcome as explicit selection of the golden workflow for that outcome. If the user gives no task, ask what they want done; do not invent a project or restart a previous goal.

Read and follow the shared [Lunacy native contract](../lunacy/SKILL.md) and [golden workflow](../lunacy/orchestrator/IMPROVEMENT.md). Apply their relevant references progressively rather than duplicating their rules here. Lunacy can handle a newly authorized, scoped task in an existing repository when current authority and ownership/effect checks permit it; “new” describes the work, not the repository's age. A new task, filename, or installation does not migrate existing or provenance-uncertain work, which retains its original contract and owner.

Before planning dispatch, honor task-scoped worker choices under [Worker model selection](../lunacy/orchestrator/WORKER-MODELS.md). When the user says `choose workers` (or asks to customize them), show choices from the current Codex catalog and ask for the `bulk` and `judgment` roles plus supported reasoning efforts. Accept exact choices supplied with the task without redundant questions. With no request to customize, preserve Luna/max and Sol/medium defaults; never require a picker on every invocation. This is a conversational launch selector, not a modification of Codex's global model picker.

For each meaningful authorized outcome: parent frames success → real task-selected consultation → actual ADHD with focus/convergence → detailed adopted `TASK.md` roadmap → coherent Lunacy workers implement/test/self-review → parent independently accepts → authorized delivery. This substantive sequence applies even to routine Golden work. Use actual skills and exact authorized routes, not summaries, cached outputs relabelled as new calls, simulated agents, or silent substitution. A new unbound cycle defaults to a fresh native `gpt-6-astra` / `high` consultation. Explicit `pro` uses direct `chatgpt-web/pro` / `ultra`; explicit `auto` remains Pro-first and may select Astra/high only from known pre-binding unavailability. Preserve an existing task binding and reuse applicable same-cycle advice. There is no automatic post-start failover or replay, including when an attempt's effects are unknown.

Follow the shared workflow's [bounded advice](../lunacy/orchestrator/IMPROVEMENT.md) policy for cold-complete, small packets, honest UTF-8 measurement and cache claims; stable prefixes are only cache-friendly, never proof of a hit or savings.

Keep one compact Golden current-stage entry in the existing parent-owned `TASK.md`: cycle/outcome, stage/status, references to actual completed outputs and existing assignments/handles, and next action/blocker. Update it before advancing and reconcile the cited output and handles on continuation; a completion label alone is insufficient. Missing or partial consultation/ADHD output pauses dependent advancement, though independent already-authorized work may continue without entering later stages. Suggest installation or enablement once when ADHD is unavailable, accurately distinguishing known uninstalled from disabled or not loaded; never guess a source or command, auto-install, or substitute. Explicit Golden selection opts into the actual ADHD skill despite its routine skip heuristic. Generators retain that skill's isolation and no-ranking rules: pass relevant facts or questions, not an adviser preference as the selected answer.

GPT-6 Astra/high is the recommended parent preset, not something this shortcut selects or verifies. Tell the user if the actual parent setting is unconfirmed; never create a shadow parent. Normally one implementation worker, up to four only for independent work under the shared routing rules.

A finite task ends when all authorized outcomes are accepted, and stale continuation does not restart it. Multiple coherent slices and same-owner testing or repair stay within delivery, not new cycles. A materially distinct authorized outcome after acceptance starts a fresh consultation and actual ADHD; same-cycle applicable advice/proof is reused on resume. Material contradictory facts require a new adoption and affected strategy reconsideration without blindly replaying live or unknown effects. Enter ongoing improvement only when the user requests it and a viable material big win exists. The user may explicitly leave Golden for ordinary Lunacy, but the parent cannot silently skip Golden stages. Source-only and design-only tasks deliver only their authorized artifacts. This shortcut does not start a scheduler, reactivate a goal, grant publication permissions, or change global/model defaults.
